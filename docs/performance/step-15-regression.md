The stricter public-profile check retains a reference to the original video after closing the viewer. Before the correction it was detached and paused, but still had its source attribute. Earlier checks only verified that the viewer/video nodes disappeared from the document; those checks did not establish decoder/source cleanup for a retained detached element. The failing live assertion is preserved in the Step 15 archive.

`videoResourceRef` now uses the installed React 19 ref-cleanup contract to capture each attached video and pause it, disable preload, remove the source and reset the media element when that exact node is detached. The imported callback has stable identity: normal rerenders, mute changes, index changes and feedback updates do not detach or reinitialize the player. Each element has independent cleanup, including individual removal or whole-viewer unmount. No design, source rendition, autoplay policy, source URL, security rule or playback controls change.

Three focused runtime/wiring tests cover attachment without playback work, cleanup of the captured element, repeated cleanup, null refs and independence of another mounted player. The deployed lifecycle test must additionally verify same-element resume, manual-pause preservation, actual touch closing, and the detached element's paused/source-free state. This narrow correction addresses a resource issue found by the required final regression; it is not an unrelated feature.
